# Vadila AI — مساعد ذكاء اصطناعي مفتوح المصدر لأندرويد

تطبيق يجمع **Claude** و**ChatGPT** و**Gemini** ونماذج مفتوحة المصدر في مكان واحد، ويعمل بمفاتيحك الرسمية (تبقى على هاتفك فقط).

## القدرات
- محادثة ببث مباشر للإجابة، وتنسيق Markdown وجداول وكتل كود ملوّنة.
- **تلقائي**: يختار أفضل نموذج متاح، وإذا انتهت حصة خدمة مجانية ينتقل إلى التالية دون توقف.
- **مجلس الثلاثة**: يسأل Claude وChatGPT وGemini معًا ثم يجمع أدق إجابة.
- مرفقات: صور، فيديو، صوت، PDF، Word، Excel، PowerPoint، ملفات نصية وأرشيف ZIP، وروابط يوتيوب ومواقع.
- بحث في الويب مع المصادر (Gemini / Claude / Groq Compound، واحتياطًا ويكيبيديا).
- صوت: إملاء بكل اللغات، قراءة الردود بأصوات طبيعية، رسائل صوتية، و**مكالمة مباشرة** مع الذكاء (Gemini Live) مع الكاميرا.
- استوديو الصور: رسم وتعديل بالذكاء، وأدوات مجانية على الهاتف (إزالة الخلفية، تحسين، حدة، فلاتر، قص، تدوير).
- صنع البرامج: يكتب المشروع كاملًا، ثم ينزّله ZIP أو **يبنيه على GitHub Actions** (APK لأندرويد، Flutter لأندرويد وويندوز ولينكس وآيفون، Python لويندوز ولينكس وماك، أو موقع على GitHub Pages)، ويصلح أخطاء البناء تلقائيًا.

## الخدمات
| الخدمة | السعر | ما تضيفه |
|---|---|---|
| Gemini | مجاني بحصة يومية | الصور والفيديو والصوت والمكالمات والبحث |
| Groq | مجاني | سرعة، بحث في الويب، تحويل الصوت إلى نص |
| GitHub Models | مجاني بحساب GitHub | نماذج ChatGPT، وبناء التطبيقات |
| Mistral / OpenRouter / Cerebras | مجانية | نماذج مفتوحة المصدر |
| Claude / OpenAI | مدفوعة حسب الاستعمال | أقوى النماذج |
| Ollama على حاسوبك | مجاني بلا حدود | نماذج مفتوحة المصدر عبر شبكة البيت |

بلا أي مفتاح يعمل نموذج مجاني صغير (Pollinations) كاحتياط أخير.

## البناء
يبنيه سير العمل `.github/workflows/assistant.yml` عند كل تعديل في هذا المجلد، وينشر `VadilaAI.apk` في إصدار باسم `ai-N`.
